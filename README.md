# O'G YAM CREPS 👟

Tienda web + panel de control para vender **tenis y zapatos** de múltiples proveedores locales.

Proyecto de **Oswal Yampier Valle Barrientos** · Medellín, Colombia.

## ¿Qué incluye?

### 🛒 Tienda (público)
- Catálogo de tenis con foto, marca, nombre, precio y tallas disponibles.
- Buscador en vivo y filtros por marca y género.
- Botón **"Comprar por WhatsApp"** en cada producto (chat directo con mensaje pre-escrito incluyendo talla).
- Diseño moderno, oscuro, estética streetwear/sneaker y optimizado para celular.

### 📊 Panel de control (privado)

#### Proveedores
- Registro de proveedores con nombre, teléfono y notas.
- Cada producto se asocia a un proveedor para saber de dónde viene.

#### Productos (Fast Entry)
- Formulario rápido con **grid de tallas (35-45)**: solo toca las tallas disponibles.
- Cálculo en vivo de **ganancia y margen** por producto.
- Preview de foto al pegar la URL.
- Dropdown de proveedor por producto.

#### Dashboard de KPIs
- Total invertido, valor de venta potencial, ganancia potencial.
- Ganancia realizada (de ventas confirmadas).
- Productos en stock.
- **Desglose por proveedor**: cuánto tienes invertido con cada uno.

#### Registro de Ventas
- Marcar producto como vendido seleccionando la talla.
- Historial completo con fecha, producto, talla, proveedor, precio y ganancia.

### 💾 Respaldo
- Exportar / importar todos los datos como archivo JSON.

## Tecnología
- HTML + CSS + JavaScript puro (sin dependencias).
- Los datos se guardan en el navegador (`localStorage`).

## Cómo usar
Abre `index.html` en el navegador. Para publicarlo gratis en internet, usa **GitHub Pages**.

## Publicar en GitHub Pages
1. En el repositorio, ve a **Settings → Pages**.
2. En **Source**, elige la rama `main` y carpeta `/ (root)`.
3. Guarda. En 1-2 minutos tendrás un link público.
